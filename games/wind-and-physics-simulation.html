WHAT I BUILT

This project is a real-time outdoor environment designed to demonstrate dynamic wind simulation, environmental animation, particle effects, physics interaction, runtime controls, and basic performance optimization.

The scene consists of a forest environment with terrain, trees, grass, bushes, lighting, and physics-based objects. The main focus was to create a single runtime wind control system capable of influencing different types of Unity objects and vegetation, even when those objects use different underlying technologies.

THE
MECHANICS

  • Custom wind zone system with runtime strength, speed, direction, and turbulence values.
  • Vegetation reacts to wind through tree animation, grass shader motion, and bush movement.
  • Particle leaves with random rotation, noise, emission, and wind-driven motion.
  • Rigidbody objects respond to gravity, terrain, and wind under a shared runtime controller.
